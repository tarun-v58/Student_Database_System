# Student Database System

A REST API for managing student records, built step by step with
FastAPI and PostgreSQL.

## Requirements

- Python 3.10+
- Git

## Setup

```bash
git clone <repository-url>
cd student_database
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

```bash
python -m app.main
```

## Project structure

```
app/     application source code
tests/   automated tests
```
